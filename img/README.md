# Carpeta de imágenes

Esta carpeta está reservada para recursos gráficos, escudos y elementos visuales del proyecto.

Si se agregan imágenes locales, deben usarse con rutas relativas desde el archivo principal del sitio:

- `../img/...` si se referencian desde la raíz del proyecto
- `img/...` si se usan desde dentro de archivos HTML ubicados en el mismo nivel

Este proyecto usa una estrategia estática para ser compatible con GitHub Pages y Codespaces.
